GULLI WEB STUDIO — пакет сайта

Файлы:
- index.html — структура и текстовые блоки
- style.css — дизайн и адаптивная вёрстка
- script.js — языки, карточки, цены, WhatsApp-форма и локальный редактор

Как посмотреть:
1. Распакуйте архив.
2. Откройте index.html в браузере.

Как опубликовать бесплатно:
- Можно загрузить папку на статический хостинг (например, GitHub Pages или Netlify).
- Для Netlify обычно достаточно перетащить папку сайта в раздел ручного deploy.
- Домен покупать необязательно: можно начать с бесплатного адреса хостинга.

Важно:
- WhatsApp-кнопка открывает чат на номер +7 776 525 52 50.
- Форма не хранит заявки на сервере: она формирует сообщение и открывает WhatsApp.
- Переключатель RU / KK / EN работает (русский, казахский, английский).
- Редактор ⚙ — демонстрационный локальный редактор. Он сохраняет изменения только в localStorage данного браузера/устройства; это не серверная CMS и изменения не синхронизируются между посетителями.
- Перед публикацией замените ADMIN_PASSWORD в script.js. Поскольку это статический сайт, пароль в JS не является безопасной защитой. Не храните в таком редакторе конфиденциальные данные.
- Чтобы изменения редактора стали видны всем посетителям, потребуется обновить файлы на хостинге. Для настоящей онлайн-панели с защищённым входом нужна база данных/сервис CMS.
- Цены ориентировочные и редактируемые в script.js.
